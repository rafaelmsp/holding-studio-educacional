# THE CRIMES LIVE — Assets V3

Este diretório recebe os 68 masters premium da V3 sem sobrescrever os 55 assets estáveis de `assets/the-crimes/`.

Enquanto um campo do `manifest.json` estiver `null`, a aplicação usa automaticamente o asset legado correspondente.

Estrutura planejada:
- `global/`: 8 backgrounds globais
- `cases/<case>/cover.webp`
- `cases/<case>/portrait.webp`
- `cases/<case>/01_contexto.webp ... 08_debate.webp`
- `cases/<case>/mobile-cover.webp`

Textos, botões, símbolos e HUD permanecem HTML/CSS/SVG.
